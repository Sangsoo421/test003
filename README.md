# 드래곤볼(아·막·파) 온라인

친구들이 각자 휴대폰으로 링크에 들어와 함께 하는 실시간 손동작 게임입니다. 모두 동시에 기술을 고르면 서버가 한꺼번에 공개하고 판정합니다. 규칙은 게임 안의 **📖 룰** 버튼이나 `prd.md` §3에 있습니다.

## 같이 하는 방법

| 상황 | 방법 |
|---|---|
| 서로 다른 곳(다른 와이파이, LTE·5G)에서 | 인터넷에 배포한 주소로 접속합니다 → [인터넷에 배포하기](#인터넷에-배포하기) |
| 같은 와이파이에서 | 한 PC에서 `npm start`를 실행하고, 출력된 "같은 Wi-Fi에서" 주소로 접속합니다 |

방을 만든 사람이 링크 복사나 QR 코드로 방 주소를 나눠 주면 됩니다. 방을 만든 사람은 입장 화면에서 **진행만 하기**를 고르면 게임에 참가하지 않고 진행만 할 수 있습니다.

## 이 PC에서 실행하기

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start          # http://localhost:3000
```

## 인터넷에 배포하기

[Render](https://render.com) 무료 플랜 기준입니다. 이 저장소에 `render.yaml`이 들어 있어 설정을 따로 입력할 필요가 없습니다.

1. 이 폴더를 GitHub 저장소로 올립니다.
2. Render에 GitHub 계정으로 가입하고 **New → Blueprint**에서 그 저장소를 고릅니다.
3. 배포가 끝나면 `https://<서비스이름>.onrender.com` 주소가 생깁니다. 이 주소를 친구들에게 보내면 됩니다.

알아 둘 점:
- 무료 플랜은 15분 동안 아무도 접속하지 않으면 잠들고, 다음 접속 때 깨어나는 데 30초~1분쯤 걸립니다.
- 방 정보는 서버 메모리에만 있습니다. 서버가 다시 시작되거나 잠들면 진행 중이던 방은 사라집니다. 같은 이유로 인스턴스(서버 수)는 1개로 둬야 합니다.
- Railway, Fly.io 등 WebSocket을 지원하는 다른 Node.js 호스팅에서도 `npm ci --omit=dev` → `node server/index.js`로 실행하면 됩니다. 포트는 `PORT` 환경 변수를 따릅니다.

환경 변수 (모두 선택):

| 이름 | 설명 |
|---|---|
| `PORT` | 서버 포트 (기본 3000, 배포 서비스가 자동으로 넣어 줌) |
| `PUBLIC_URL` | 공유 링크·QR에 쓸 주소를 고정할 때 (예: `https://my-game.example.com`). 없으면 접속한 주소를 그대로 씁니다 |
| `MAX_ROOMS` | 동시에 열 수 있는 방 수 (기본 500) |

## 테스트

```bash
npm test                                   # 규칙·진행 단위 테스트
npx playwright install chromium webkit     # 처음 한 번
npm run test:e2e                           # 브라우저 E2E 테스트 (약 8분)
```
